# 보안·개인정보 감사

검토일 2026-11-16 · 배포 대상 `v0.1.1`

`v0.1.2`는 설치자가 지정한 Strata 체크아웃의 현재 커밋을 내보냅니다. Git 대체 객체 차단, 아카이브 형식 검사, 런타임 권한 제한은 계속 사용합니다. 아래 의존성 조회는 당시 감사한 0.1.60 기준 소스에 해당합니다.

검토 범위는 공개할 Git 릴리스, 설치·시작·검증 코드, UTF-8 제약 패치, 정적 웹 안내와 ZIP입니다. 배포 대상에서 비공개 정보가 섞였는지 확인하기 위해 분리한 실험 워크트리와 기존 릴리스의 Git 이력도 검사했습니다. 기존 운영 서버, 대화 원문, 개인 PC 설정과 자격증명 저장소는 이 패키지의 감사 범위 밖입니다.

## 수정한 항목

| 항목 | 영향 | 처리 |
| --- | --- | --- |
| 로컬 Git 객체 대체 | 고정 커밋 ID를 검사해도 로컬 Git 대체 설정이 내보내는 소스에 영향을 줄 수 있었습니다. | `rev-parse`와 `archive`에서 대체 객체 기능을 끕니다. 소스 아카이브는 일반 파일과 디렉터리만 허용하며 Python `data` 필터를 적용합니다. |
| 기존 소스 체크아웃 | 소스 경로를 잘못 지정하고 이전 설치 예시를 실행하면 기존 체크아웃의 브랜치가 바뀔 수 있었습니다. | 새 소스 디렉터리를 먼저 만들고 실패하면 이후 명령을 실행하지 않습니다. 이미 고정 커밋을 갖고 있다면 `prepare`에 직접 넘기는 절차를 문서화했습니다. |
| 설치 경로의 접근 범위 | 기존 런타임과 설치 메타데이터의 접근 권한은 셸의 `umask`에 좌우됐습니다. | 새 런타임을 POSIX `0700`으로 만들고, 경로 메타데이터·임시 프로필·정책 스위치는 제한된 임시 파일을 써서 원자적으로 교체합니다. 기존 런타임의 권한은 설치자가 점검할 수 있습니다. |
| 원격 이미지와 외부 도구 | 루프백 바인딩만으로 Strata 프로필의 외부 연동을 제어할 수는 없습니다. | `serve --offline`을 전달하도록 하고 설치 예시에서 사용합니다. 네트워크 연동이 필요한 경우는 프로필과 앱의 설정에 따릅니다. |

Python 정적 검사에서 `subprocess` 사용 경고는 고정 실행 파일과 인자 배열을 전달하고 셸을 거치지 않는 호출임을 확인했습니다. 아카이브 추출은 형식 검사와 `data` 필터로 검증합니다. [Python tarfile 추출 필터](https://docs.python.org/3.12/library/tarfile.html#extraction-filters)

## 배포 파일과 개인정보

- 저장소와 ZIP에서 API 키·토큰·개인 연락처·개인 장치 경로·내부 주소·대화 원문을 찾는 검사를 수행했습니다. detect-secrets가 표시한 3개는 공개 Strata 커밋 ID, 토큰 지문, 전이표 지문이었습니다. Git 이력에는 일반 릴리스 작성자 표기만 사용합니다.
- 검증 도구는 환경의 `STRATA_API_KEY`를 `127.0.0.1` 요청에만 사용합니다. 리디렉션을 거부하고 프록시를 사용하지 않는 HTTP 클라이언트를 씁니다. 시작 코드가 만드는 임시 프로필에는 기존 설정값이 들어갈 수 있어 파일을 제한된 디렉터리에 두고 정상 종료 때 정리합니다. 강제 종료 뒤 자격증명이 포함된 임시 디렉터리가 남았는지 확인할 수 있습니다.
- 웹 안내는 외부 스크립트·폰트·분석 도구 없이 실행됩니다. 페이지에 입력한 경로를 브라우저 저장소나 네트워크에 보내는 코드는 없습니다. 스크립트는 CSP 해시로 허용하고 명령 표시에는 텍스트만 사용합니다. 복사는 버튼을 눌렀을 때 현재 명령 또는 에이전트 요청문을 클립보드에 넣습니다. 제3자 웹 호스트에 올리면 사이트 접근 기록에는 해당 호스트의 운영 정책이 적용됩니다.
- 패키지는 서버를 루프백 주소에 바인드합니다. 기존 프로필이 `api_monitor`를 활성화하면 Strata가 최근 요청과 응답을 메모리에 보관할 수 있습니다. 공유 호스트에서 설치할 때는 인증과 실제 프로필의 모니터·도구 옵션을 확인하세요. 공개 이슈에는 합성 입력과 민감정보를 가린 로그를 사용하세요. [Strata 보안 문서](https://github.com/Niko1221/Strata/security)

## 외부 의존성과 검증 범위

- 고정 Strata 커밋의 Linux·Python 3.12 이상 런타임 및 빌드 요구사항에 선언된 PyPI 버전 16개를 OSV에서 조회했습니다. 조회 시점에 일치한 권고는 0건이었습니다. 실제 설치에 추가되는 전이 의존성, CUDA·드라이버·C++ 의존성과 전체 Strata 소스는 이 조회 범위 밖입니다. [OSV 조회 API](https://google.github.io/osv.dev/api/)
- 이 감사에서는 공개 소스 패치 적용, 토크나이저 지문, 파일 구성과 웹 상호작용을 검증했습니다. Linux의 실제 파일 권한 테스트와 CUDA 실모델 실행은 대상 설치 환경에서 확인할 항목입니다. 패키지를 로컬 보안 경계나 별도 샌드박스로 사용하려면 운영 환경의 권한과 네트워크 정책을 따로 관리합니다.
